1. 保持修改聚焦，并记录其目的。
2. 不得加入密钥、运行时数据库、生产配置或未经授权的媒体。
3. 保留许可证、声明和来源署名组件。
4. 提交修改前运行 README 所列本地检查。
5. 新媒体必须在英文版 `ASSET-LICENSES.md` 中登记。

提交贡献即表示你确认有权按本仓库的 AGPL-3.0-only 许可证及适用附加条款提交该贡献。
