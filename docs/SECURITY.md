# Security policy

English | [简体中文](https://github.com/BaizhouziYou/xintinglei-website/blob/main/docs/SECURITY.zh-CN.md)

Do not report vulnerabilities through public issues when they could expose deployment details, credentials, or player information. Contact the maintainer privately through the contact route listed in the project documentation.

Never commit databases, `.env` files, certificates, ACME challenge files, access logs, or production server configuration. Before reporting a bug, remove player names, IP addresses, tokens, and local file paths.
